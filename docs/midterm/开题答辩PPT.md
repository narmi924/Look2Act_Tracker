这份开题汇报的PPT内容主要分为封面目录以及五个核心部分，以下是每一页（或各部分逻辑页面）的详细内容描述：

**封面与目录**
*   **封面**：明确了课题名称为《实时视线追踪技术研究与实现》。
*   **目录**：列出了汇报的六个环节，依次为：背景与应用动机、问题定义与研究目标、核心技术路线、计划实验与评估指标、具体进度安排，以及最后的提问环节。

**第一部分：背景与应用动机**
*   **技术定义**：解释了视线追踪技术是通过分析人眼运动状态来估计注视方向或位置，是人机交互、智能驾驶等领域的基础技术。
*   **技术对比**：对比了四种技术路线。传统眼动追踪依赖红外摄像头，精度高但成本高、部署复杂；基于普通RGB摄像头的非接触式追踪实现简单，但对姿态和光照敏感；端到端深度学习方法表达能力强，但跨设备性能下降明显；最终引出本课题倾向的“深度学习的外观建模能力+几何约束”方法，以兼顾精度与泛化能力。
*   **数据集展示**：列举了现有的主要数据集，包括MPIIGaze（基于外貌的野外凝视估计）、Gaze360（野外物理无限制）和UnityEyes（合成3D图像）。

**第二部分：问题定义与研究目标**
*   **应用场景定义**：聚焦于任意Windows笔记本电脑，使用普通前置RGB摄像头，在日常使用距离下获取屏幕注视点坐标 (x, y)。
*   **研究目标**：明确了三大目标：1）实现实时运行（帧率≥15 FPS，端到端延迟可控）；2）跨用户、跨设备可用（仅需少量校准甚至免校准）；3）支持桌面交互，如注视光标和凝视触发等。

**第三部分：核心技术路线**
*   **原理解析（3D视线回归+几何映射）**：详细绘制了空间几何与处理流程图。系统通过面部图像采集提取眼部区域（ROI），利用深度学习模型回归出相机坐标系下的3D视线向量，结合头部姿态校正（Yaw/Pitch/Roll）和屏幕几何参数（通过校准获取），最终计算出视线射线与屏幕平面的交点，得出二维注视点。
*   **数据策略讨论**：探讨了现有数据集的局限性。虽然现有数据集规模大、标注全，但与真实桌面摄像头存在显著的域差异（如纹理、反光、曝光等），合成数据训练出的模型在映射到真实屏幕时误差容易放大。因此提出了“公开真实数据预训练 + 自采数据微调 + 真实部署评估”的策略。
*   **交互系统设计**：展示了交互界面的基础设计。基础交互包括注视点可视化，以及稳定凝视3秒即可触发点击或启动程序（展示了包含QQ、微信、相机、井字棋、浏览器等应用面板的界面）。此外，还计划尝试拓展“系统级输入注入”以实现跨应用控制。

**第四部分：计划实验与评估指标**
*   **对照/消融实验设计**：计划针对四个维度进行对比实验：模型输出（2D平面回归 vs 3D深度回归）、头部姿势（使用 vs 不使用）、眼-屏距离（使用 vs 不使用）以及校准次数（3*3个点 vs 5*5个点）。
*   **评判指标**：制定了四个维度的评估标准，分别是精度（角度误差、像素误差）、稳定性（抖动RMS、漂移率）、实时性（FPS、端到端延迟）和可用性（单次有效率、失败场景统计）。

**第五部分：具体进度安排**
*   **任务甘特图**：列出了汇报人从2025年11月到2026年5月的详细毕业设计任务安排。包括学习图像处理知识、视线数据采集、模型训练、用户校准与映射、性能测试及论文写作，并定于2026年5月18日进行答辩。
*   **最新进展（采集系统开发）**：展示了已完成的“隐私保护数据采集系统（Gaze Dataset Collector）”的多个界面截图。流程包括：1) 配置用户的ID、是否戴眼镜、相机和分辨率；2) 检查人脸、头姿、ArUco码和距离等参数；3) 进行25个红点的正式视线采集（稳定期500ms后以15fps记录）；4) 采集完成并自动打包导出含有特征参数的数据表（CSV）。
*   **最新进展（志愿采集者测试）**：展示了多张志愿者在不同光照环境和桌面布局下使用该系统进行数据采集的实际工作照片（部分志愿者手持ArUco标记卡片配合测试）。
