# 五、手动插入时的规则

1. **不要把引用放在标题上。**学校规范明确要求不得将引用标示置于各级标题处。
2. **引用放在“被引用观点”的句末。**例如：
   `……仍然有限[2]。`
   到 Word 里把 `[2]` 设为上标。
3. **自己的系统事实不加参考文献。**例如“本文数据集包含31名用户、16台设备和7395条有效样本”“系统支持Classic和Deep模式”“EXE打包约467 MB”，这些是你的工作结果，不引用外部文献。
4. **内部文档不进参考文献。**README、代码证据文档、master guide、中期报告、Codex文档都只能作为你写作时的事实依据，不能作为最终参考文献。
5. **同一段不要塞太多引用。**第一章和第二章引用密度高一些正常；第三章到第七章主要写你的系统和实验，引用点应少而准。

最稳的操作是：先把上面的 18 篇参考文献放到文末，再按“插入位置表”逐个搜索定位句，手动插入编号并设置上标。
