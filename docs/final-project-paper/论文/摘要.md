\## 摘  要



视线追踪技术能够估计用户的注视方向或屏幕注视位置，在人机交互、辅助输入和无接触控制等场景中具有应用价值。针对专用眼动仪成本高、部署复杂，而普通 RGB 摄像头视线追踪易受光照、头姿、设备和个体差异影响的问题，本文设计并实现了一套基于普通 Windows 计算机和 RGB 摄像头的实时视线追踪与注视交互系统 Look2Act。系统构建了从数据采集、眼区裁剪、模型训练、三维视线估计、屏幕几何映射、用户校准、时序平滑到注视交互的完整软件链路，并实现 Classic 与 Deep 两种运行模式。其中，Classic 模式基于传统图像处理提取眼部特征，Deep 模式基于 GazeNetV2 模型回归三维视线方向。本文自建了包含 31 名用户、16 台设备和 7395 条有效样本的数据集，完成了模型训练、ONNX 导出和 Windows 本地软件部署。实验结果表明，GazeNetV2 在固定测试集上取得 2.8206° 的平均角度误差，在 31 名用户留一交叉验证中取得 2.4788° 的平均角度误差和 321.3820 px 的平均屏幕像素误差。校准实验和系统测试表明，用户校准、几何映射和平滑处理对普通摄像头视线交互的可用性具有重要影响。最终系统能够完成摄像头预览、25 点校准、实时追踪、全屏验证和注视交互演示，适用于注视点可视化、大目标选择和低成本视线交互原型验证。



关键词：视线追踪；普通 RGB 摄像头；深度学习；用户校准；注视交互

\## ABSTRACT



Gaze tracking estimates a user’s gaze direction or screen point of gaze and has potential applications in human-computer interaction, assistive input, and touch-free control. Dedicated eye trackers can provide high accuracy, but they are usually expensive and difficult to deploy. In contrast, gaze tracking with a standard RGB webcam is low-cost but sensitive to illumination, head pose, device configuration, and individual differences. To address these issues, this thesis designs and implements Look2Act, a real-time gaze tracking and gaze interaction system for ordinary Windows computers and RGB webcams. The system builds a complete software pipeline from data collection, eye-region extraction, model training, 3D gaze estimation, screen geometry mapping, user calibration, temporal smoothing, to gaze-based interaction. Two running modes are implemented: the Classic mode extracts eye features using traditional image processing, while the Deep mode estimates 3D gaze direction using the proposed GazeNetV2 model. A self-collected dataset containing 31 users, 16 devices, and 7,395 valid samples is constructed for training and evaluation. The trained model is exported to ONNX and deployed in a local Windows application. Experimental results show that GazeNetV2 achieves a mean angular error of 2.8206° on the fixed test set, and obtains a mean angular error of 2.4788° and a mean screen-space error of 321.3820 px in 31-user leave-one-user-out evaluation. Calibration experiments and system tests indicate that user calibration, geometric mapping, and temporal smoothing are important for the usability of webcam-based gaze interaction. The final system supports camera preview, 25-point calibration, real-time tracking, fullscreen verification, and gaze interaction demonstration, making it suitable for gaze visualization, large-target selection, and low-cost gaze interaction prototyping.



Keywords: gaze tracking; RGB webcam; deep learning; user calibration; gaze interaction
