# 摄像头预览页面使用说明

## 概述

摄像头预览页面 (`src/ui/camera_page.py`) 提供实时摄像头画面显示，并叠加人脸检测框和眼部关键点可视化。

## 功能特性

### 1. 实时摄像头预览
- 显示摄像头实时画面
- 水平镜像翻转（符合用户习惯）
- 自适应窗口大小

### 2. 人脸检测可视化
- **人脸边界框**：绿色矩形框标识检测到的人脸
- **68 个关键点**：不同颜色标识不同面部区域
  - 青色：脸部轮廓（点 0-16）
  - 黄色：眉毛（点 17-26）
  - 品红：鼻子（点 27-35）
  - 红色：眼睛（点 36-47）
  - 蓝色：嘴巴（点 48-67）

### 3. 实时状态显示
- **FPS**：当前帧率（每秒更新）
- **人脸检测状态**：显示是否检测到人脸
- **错误信息**：显示摄像头或检测错误

### 4. 控制按钮
- **启动预览**：开始摄像头采集和人脸检测
- **停止预览**：停止摄像头并释放资源

## 使用方法

### 独立测试

```bash
# 在项目根目录下运行
conda run -n gaze-env python test_camera_page.py
```

### 集成到主窗口

```python
from src.ui.camera_page import CameraPage

# 创建摄像头预览页面
camera_page = CameraPage()

# 添加到主窗口的导航栏
main_window.addSubInterface(camera_page, "摄像头预览")
```

## 技术实现

### 架构设计

```
CameraPage (主界面)
    ├── CameraStream (摄像头流管理)
    │   └── _CaptureWorker (后台线程读取帧)
    └── FaceDetector (人脸检测)
        └── MediaPipe FaceMesh
```

### 性能优化

1. **后台线程**：摄像头读取在独立线程中运行，避免阻塞 UI
2. **帧率限制**：默认 30 FPS，可配置
3. **检测频率**：每 2 帧执行一次人脸检测，减少计算负担
4. **FPS 更新**：每秒更新一次 FPS 显示，避免频繁刷新

### 关键参数

- **摄像头索引**：默认 0（主摄像头）
- **分辨率**：默认 1280x720
- **帧率限制**：30 FPS
- **眼部裁剪尺寸**：128x128 像素

## 依赖项

- PyQt6：GUI 框架
- qfluentwidgets：Fluent Design 风格组件
- OpenCV：摄像头读取和图像处理
- MediaPipe：人脸检测和关键点提取
- NumPy：图像数据处理

## 注意事项

1. **摄像头权限**：确保应用有摄像头访问权限
2. **资源释放**：关闭窗口时自动停止摄像头并释放资源
3. **线程安全**：使用 Qt 信号机制确保线程安全
4. **错误处理**：摄像头打开失败或读取失败时显示错误信息
