## 来源审计与复用边界

旧数据的三维 `gaze_x/y/z` 由屏幕目标、通用屏幕/相机几何和距离代理**计算**，不是独立测得的眼球方向。`scripts/preprocess.py` 会写 processed 数据，未运行。固定抽样解码 31 张 raw 拼接图（每会话一张，6 张 240×640、25 张 128×640）与 32 对 processed 眼图（128×128）；raw 前两块是眼部拼接图，不能恢复原相机绝对坐标。预处理代码在右眼缺失时可能翻转左眼代替；此有限样本中未发现空右块或近似翻转左眼的右图，**不代表全量没有发生**。没有批量运行 FaceMesh、重新生成旧数据或上传图像。

## 固定方法和质量

F0 按现有 `fuse_eye_features` 将可用的暗色质心相机坐标求均值，再除以相机 W/H 并保留原 clamp；与记录的 `raw_point` 最大绝对差为 **0**。F1 保留左右眼各自的 `x/Wc,y/Hc`。F2/F3 分别将同帧暗色质心/虹膜中心投影到各眼固定眼角 `a→b`：`c=(a+b)/2`、`w=||b-a||`、`ex=(b-a)/w`、`ey=(-ex_y,ex_x)`，输出 `dot(q-c,ex)/w, dot(q-c,ey)/w`。左右原索引为 33→133、362→263；拒绝缺失、非有限、ROI/相机坐标不一致和 `w<2 px`，不填零或互相复制。该局部表示具二维相似变换不变性，不保证真实三维头动下不变。

C0 只输出训练标签均值；H0 为 yaw/pitch/roll；F2+H/F3+H 只是拼接现有数值后用同一回归。Classic 未在线计算姿态，H 使用**录制的**六点、通用人脸模型、近似相机内参和畸变，经现有 PnP 估计器离线派生，标记 `derived_offline`。六点/旋转/有限性检查后，以预先固定的 20 px 重投影 RMSE 上限筛选，不插值、不平滑；2148/2154 可用，残差中位 7.60 px、P95 9.20 px。通用模型的尺度和平移不是精确测量。欧拉角出现 ±180° 分支跨越，同一连续片段内有 71 次单轴数值跳变超过 90°；例如训练 A 的 pitch 范围 173.4°～178.8°，留出 A 可到 −180°。这严重影响线性头姿对照，不能把其失败解释成“头姿无用”。

源 2154/2154 有效，F0/F1/F2/F3 均 2154/2154 可计算；H 2148/2154。按 `target_at` 对**源时间**与实际绘制关联：measurement 1662、settling 401、time_uncertain 91、unavailable 0。主误差只用 measurement；记录的 1525 条 UI 拒绝和 629 条未消费源观测不作为生产样本过滤条件。A 第一轮 9 次目标展示/391 帧训练，A 第二轮 9 次/388 帧留出；B 12 次展示，自然 261、yaw 313、pitch 309 帧。时间间隔 >250 ms、会话/连续性变化、失败、暂停、缺口及目标切换不跨接运动差分。源时间是主机 `VideoCapture.read` 完成时间，不是曝光时间；目标绘制提交亦非物理点亮时间。

二维归一化目标的带截距岭回归固定 `λ=0.01`。对 `G` 次训练目标展示，段 `g` 有 `n_g` 帧时，每帧权重为 `1/(G n_g)`；每段总权重 `1/G`，全体样本权重之和为 1。最小化 `Σᵢ wᵢ‖zᵢB+b−yᵢ‖² + 0.01‖B‖²`，其中 `z` 仅用训练集加权均值/标准差标准化，截距 `b` 不惩罚，以 `lstsq` 稳定求解。模型输出记录实际展示段数、weight_sum、权重定义、λ 和目标函数；运行清单与冻结的样本清单在拟合前写入本地忽略目录。所有方法只用纯数值视觉/几何输入，目标、指令、时间、身份不入预测。每对方法另在共同**训练和测试身份**上重拟合并比较；共同 ID 清单在本地 `paired_support.json`。无屏幕截断、时序平滑或按误差删样本。A2 是同一九个屏幕位置的重复展示，**不是**未见位置或跨用户测试；B 同样是这个会话的压力测试。

`abba5d4` 的**旧实现**使用 `wᵢ=1/n_g`，九段训练的总权重为 9；在损失归一化到总权重 1 后，它等价于 `λ=0.01/9`。这与固定 `λ=0.01` 的修正实现不是同一目标函数。旧输出原样保留在旧 analysis_run 目录，不与下方修正结果混用，也没有为新结果重新选择 λ、特征或会话。例如旧实现→修正实现的 A 留出均值分别为 F0 `359.3→354.4`、F1 `279.7→302.0`、F2 `203.5→202.8`、F3 `181.1→179.3` px；B yaw 分别为 `845.5→832.1`、`855.3→780.2`、`360.1→360.1`、`654.5→648.2` px。数值变化来自固定权重定义的修正，不是精度优化或超参数搜索。

直接回答：归一化权重下 F1 在 A 和三个 B 组均优于 F0；F2 相比 F1 在四个留出组都明显降低偏差，是本会话最一致的候选；F3 在全部 A 留出略好，但匹配 B 目标的 A 子集及三个 B 组均更差，不能据此替换 F2；简单加入原始欧拉头姿因分支跳变与训练姿态范围有限而显著恶化，尚不能评价合理连续姿态表达的潜力。旧 raw/processed 可复核目标、划分和派生标签，不能补做本轮相机坐标特征或眼动时序。下一轮**候选**仅是在新会话中预先固定 F2 对照和头动/质量检查，先验证单会话结果可否复现；本轮不实施，不切换在线后端。

## 复现与限制

Git Bash，从仓库根目录使用已授权隔离 Python；`select` 在多于一个合格 AB 时拒绝自动选择，不依据误差选源。所有输出只在 Git 忽略的 `experiment_sessions/r4_runs/`；`audit` 只读旧源，解码最多 32 对/组。

```bash
R1_PY="E:/TMP/look2act-r1-env/Scripts/python.exe"
"$R1_PY" scripts/r4_features.py audit --raw dataset_raw --processed dataset_processed
"$R1_PY" scripts/r4_features.py selftest
AB_SESSION="$("$R1_PY" scripts/r4_features.py select)"
"$R1_PY" scripts/r4_features.py run --session "$AB_SESSION"
QT_QPA_PLATFORM=offscreen "$R1_PY" -m pytest tests/test_r4_feature_baselines.py -q
```

本机：新增修复回归在生产代码未改时定向运行 **5 failed、10 deselected**（旧 R4 全套先前为 10 passed）；修复后 R4 合成数值/目录 **15 passed**。R1/R2/R3 相关短套件 **293 passed、2 主动 deselected**（`test_error_callback` 会尝试初始化相机，`test_process_frame_with_mock_frame` 涉及本机模型/原生检测器；均未运行）；独立设置页 **13 passed、14 条第三方 warnings**；合计自动测试 **321 passed、0 failed、0 skipped、2 主动 deselected**。R3 合成录制回放 **20/20 一致、0 mismatch、0 integrity issue**。没有访问真实相机、执行系统操作、重采旧数据或修改用户原始记录。远端 CI 未在本报告时声称通过；R1/R2 完整人工交互、未绘制前跳过/长暂停/异常退出等实机路径仍待验证，历史原生 access violation 根因未解决。单会话探索性留出在本次分析后已被观察，后续方法选择不能再称它为未使用的最终测试集。
